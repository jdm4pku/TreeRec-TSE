Thank you for participating in this user study. Your task is to help us evaluate software artifact recommendation tools.

For each scenario below, imagine you are a developer in that situation. Write a short search query (1-3 sentences, in English) describing what you would search for to find a suitable software artifact (e.g., a package or a pretrained model).

- Do NOT look up the answer; just write what comes to mind based on the scenario.
